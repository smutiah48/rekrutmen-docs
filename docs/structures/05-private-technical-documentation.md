# Batas Publikasi Dokumentasi Teknis

Repositori ini **hanya menampilkan arsitektur, fitur, spesifikasi, rencana, dan desain**. Sumber asli, indeks nama fungsi yang terperinci, serta peta penjelasan baris 1:1 disimpan **hanya di repository PRIVATE** karena dapat mengungkap rincian implementasi dan alur internal.

Repositori publik tidak dimaksudkan untuk menyimpan source aplikasi, konfigurasi akses, atau data pribadi pelamar. Setiap aset dan screenshot perlu ditinjau sebelum digunakan; seluruh isi repositori publik dapat diunduh oleh siapa pun.
