# Struktur Dokumentasi Publik

Repositori ini menyediakan gambaran proyek dan desain tanpa menyertakan kode aplikasi, konfigurasi internal, atau dokumentasi teknis privat.

| Lokasi | Isi |
|---|---|
| `README.md` | Gambaran proyek dan batasan dokumentasi. |
| `DESIGN.md` | Prinsip visual dan pengalaman pengguna. |
| `index.html` | Viewer dokumentasi. |
| `docs/specs/` | Spesifikasi tingkat umum. |
| `docs/plans/` | Rencana pengujian dan pemeliharaan. |
| `docs/structures/` | Gambaran arsitektur dan komponen. |
| `assets/` | Aset untuk viewer dan materi yang disediakan dalam repositori publik. |

Setiap aset dan screenshot perlu ditinjau untuk privasi, ketepatan konteks, serta izin institusi sebelum digunakan sebagai materi publik.
